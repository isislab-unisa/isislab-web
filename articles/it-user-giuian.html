L' argomento
Mi sto occupando di Java 3d come tecnologia di sviluppo di ambienti virtuali interattivi
Specifiche
Mi sono occupato della valuazione di java 3d e unreal engine come piattaforme per lo sviluppo di ambienti virtuali. Dopo aver scelto di proseguire la trattazione di java 3d, per via della sua flessibilità, ho proseguito con la valutazione della tecnologia in termini di "quanto è viva" . In particolare: ho provato a sviluppare semplici applicativi "ex novo" in java 3d ho ricercato riguardo la varietà di formati supportati dalla piattaforma. L'ultimo punto ha un peso in quanto ci può dare una misura di "quanto up to date" sia java 3d.

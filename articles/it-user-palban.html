Pietro Albano

Il lavoro di tirocinio e tesi svolto per la laurea di primo livello è stato lo studio di linguaggi e ambienti di sviluppo per dispositivi mobile, in particolare di j2me ( Java Micro Edition 2) e della piattaforma di sviluppo offerta dalla Nokia. Il lavoro è comflutito nello sviluppo di un software client-server capace di monitorare, grazie ad un sistema di videosorveglianza, un ambiente remoto direttamente su dispositivi mobili.

Seminari:

  • Java Micro Edition vs .NET (architetture e confronti)
  • Studio ed analisi di un possibile porting di podcast su dispositivi wireless

Tesi:

  • Sistema di monitoraggio remoto su dispositivi wireless
  • Sorgenti Software Mobile srcmobile.tar.gz release 2 ( capace di operare in ambiente distribuito )
  • Sorgenti Software Server srcserver.tar.gz release 2 ( capace di operare in ambiente distribuito + porting in ambiente unix-like )

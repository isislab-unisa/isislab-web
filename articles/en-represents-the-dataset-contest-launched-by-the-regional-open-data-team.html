The regional Open Data team launches the " Rappresenta il dataset " contest on the Open Data portal of the Campania Region for the exploitation of Open data.

It is an initiative that makes it possible to exploit the technical and operational knowledge and skills to create data in an open format both for research, analysis ,and journalistic purposes. The data can be viewed with a visualization tool  that allows you to use both the data on the Campania Region portal and the data of all Open Data portals (CKAN, DKAN, Socrata, etc) that enable requests via API. The visualization tool was developed by the ISISLab team, led by prof. Scarano of the DI, University of Salerno, within the ROUTE-TO-PA European project.

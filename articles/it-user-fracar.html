Laurea Specialistica

Il lavoro svolto ha riguardato la creazione di un applicazione per smartphone, che utilizzando la realtà aumentata, implementa un libretto di manutenzione di un automobile.

In particolar modo è stata data enfasi sul individuazione di spie accese poste sul cruscotto utilizzando la fotocamera dello smartphone.

A tal proposito sono state studiate ed analizzate varie strategie che combinano l'utilizzo di framework che implementano tecniche di realtà aumentata come Metaio e l'utilizzo di tecniche proprie della computer vision implementate usando la libreria OpenCV

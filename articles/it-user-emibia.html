Emidio Andrea Bianco

Introduzione

Geogebra è un software per la matematica, rivolto soprattutto a studenti di scuole medie inferiori e superiori, che comprende geometria, algebra ed analisi.

Geogebra provvede strumenti per la geometria, quindi è possibile costruire figure geometriche come: punti, rette, coniche e funzioni.

Al contempo è possibile inserire funzioni, variabili, equazioni, calcolo di derivate ed integrali e via dicendo, oltre a disporre di tante utili funzioni.

Inizialmente, Geogebra, nato come strumento per facilitare l'apprendimento di geometria e algebra, viene, ora, applicato ai diversi progetti nei più variati campi, come: fisica, chimica, statistica ecc..

Il progetto è quello di incorporare Geogebra all'interno di CoFFEE. Dico incorporare perchè le rispettive licenze sono incompatibili tra loro.

Questo dovrà avere la finalità di poter condividere tra gli attori di CoFFEE, una o più sessioni GeoGebra.

Fornisce delle API Javascript per l'interazione degli oggetti nella versione applet, ed può esportare il tutto tramite file .ggb, che altro non sono che file XML. Viene definito anche uno schema per essi, di modo che è possibile leggere i file su (quasi) ogni versione dello stesso.

Abstract

Geogebra è un software in Java per l'apprendimento della matematica (algebra, geometria ed analisi).

L'architettura di Geogebra permette una ampia interazione con l'utente, come costruire rette, punti, funzioni, integrate, derivate e tante altre funzioni avanzate per la fisica, chimica, statistica ecc... In più ma soprattutto, permette di essere incluso in una pagina web, come applet, oltre che come programma stand-alone, fornendo delle API Javascript per la manipolazione e l'interazione degli oggetti.

Virtual Unisa Mobile

Introduzione

Il mio lavoro di tesi consiste nello sviluppo di un'applicazione grafica tridimensionale interattiva per dispositivi mobili. Per creare un'applicazione del genere vengono sfruttate le funzionalità offerte da Marmalade SDK. Marmalade SDK è uno strumento di sviluppo multipiattaforma, sia per dispositivi mobili che embedded, che permette di scrivere del codice C++ eseguibile sulle diverse piattaforme supportate(Android, iOS, Symbian, Windows Mobile...). Con Marmalade è possibile sviluppare applicazioni avanzate e di natura grafica 2D e 3D, con pieno supporto al rendering di tipo software e hardware.

In particolare l'applicazione permette di visualizzare e navigare il modello 3D dell' Università degli Studi di Salerno.

Seminari

Primo Seminario

Titolo del seminario :

Marmalade SDK Studio

Abstract :

  • Introduzione ad Marmalade SDK
  • Panoramica di Marmalade Studio, una suite di strumenti per la progettazione di applicazioni grafiche 2D-3D
  • Presentazione di una applicazione per smartphone che visualizza un modello 3D

Stato del lavoro

  • Prova di caricamento e gestione di un singolo modello del complesso universitario
  • Interazione con il modello attraverso le Pointer API di Marmalade SDK(per la gestione del touch screen)
  • Caricamento dell'intero modello dell'università
  • Pitch della camera con Accelerometro
  • Heading della camera con Bussola
  • Conversione delle coordinate di latitudine e longitudine ricevute dal GPS in world-coordinate per il modello virtuale dell'università
  • In fase di sviluppo dell'interfaccia grafica per la ricerca di un edificio...

Google Native Client

Step 1: Studio della tecnologia

Native Client è una tecnologia che permette l'utilizzo, in un ambiente sicuro, di applicazioni scritte in C o in C++ tramite il web attraverso lo scambio di messaggi asincroni, usando il browser (Google Chrome) per visualizzare i dati e prendere gli input dell'utente, JavaScript per gestire l'invio e la ricezione dei messaggi ed un plugin (Pepper) che si pone come intermediario per lo scambio di messaggi da parte del browser e del modulo Native Client, la nostra applicazione scritta in C o in C++.

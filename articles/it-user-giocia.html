Argomento tesi

Cyrano: plugin Oxwall per facilitare la comunicazione tra bambini che parlano lingue diverse.

Seminari

Oxwall - RESTful - CKAN: concetti ed esempi (20/03/2015 - 11:00) (slide qui)
In questo seminario vi parlerò delle tecnologie che sto studiando e che saranno alla base della mia tesi:
1) Oxwall: piattaforma open source per lo sviluppo di social network - una breve panoramica su come funziona e un esempio di plugin per la visualizzazione dei dati meteo;
2) Servizi RESTful: cosa sono e come possiamo accedervi facilmente in PHP e JavaScript;
3) CKAN: sistema open source per la gestione di open data - breve panoramica sulle API RESTful offerte da CKAN e presentazione di client PHP e JavaScript per utilizzarle.
Cyrano: un plugin Oxwall per la comunicazione multilingua (20/07/2015 - 10:00) (slide qui)
In questo seminario vi presenterò Cyrano, il plugin che ho sviluppato in questi mesi di tirocinio. L'obiettivo del plugin è quello di semplificare l'interazione tra bambini che parlano lingue diverse senza che l'uno parli la lingua dell'altro. Vi parlerò delle tecniche adottate per facilitare tale comunicazione e delle metodologie usate per adattare il sistema esistente senza modificare manualmente il codice sorgente di Oxwall, permettendo così una maggiore manutenibilità del codice risultante. Infine vi presenterò alcuni possibili sviluppi futuri.

"A Web Analysis Tool for an Hypergraphs Repository: hypergraph-repository.github.io" di Muhammad Tanveer Jan

Abstract : Web application developed in jekyll to collect and analyze hypergrpahs in a responsive way. Multiple libraries are used to develop the site and make is responsive which can be viewed on any device desktop or mobile. This seminar will gave you a broad idea on how you can make use of jeykll to develop cool and amazing web application. It will also gave you exposure into several other libraries like ChartJS, Grid Flexbox v2, Material Design Bootstrap, datatables, fontAwsome Icons and MichealSnik Animation library.

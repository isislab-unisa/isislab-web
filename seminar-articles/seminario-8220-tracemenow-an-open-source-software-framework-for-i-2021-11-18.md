"The increased number of smartphone-connected devices and the pervasive presence of sensors enabled the application of localization and tracking technologies in multiple contexts. However, despite the effort of the research community, the integration of an Indoor Positioning System within an application is still difficult since it requires expertise in diverse fields. In order to tackle this issue, we present TraceMeNow, an open-source framework for developing applications comprising an Indoor Positioning System based on Bluetooth Low Energy and low-cost hardware."

Aula F5 (Edificio F2), Dipartimento di Informatica - Università degli Studi di Salerno

Nell'ambito dello scambio Erasmus con University of Brighton, verrà tenuto un workshop per studenti, da Marcus Winter senior lecturer a Brighton. Il workshop è molto pratico con esperienze con il proprio portatile. Accludo una breve descrizione ed un programma più dettagliato.

Speaker : Marcus Winter

Research Interests: Human-Centred Machine Learning (HCML)

With a background in Human Computer Interaction and Ubiquitous Computing, Marcus' recent research pivots towards Human-Centred Machine Learning (HCML), focusing in particular on ML applications that directly interface with everyday users. Unlike previous research in this field, which focuses primarily on implicit/indirect interaction with ML systems (e.g. recommender systems, home automation), he is interested in exploring non-expert users' explicit/direct interacting with ML applications, e.g. to customise a system for a particular context or train it for specific problems. More info at https://edgee.co.uk

Workshop: Machine learning in the browser

The workshop consists of a presentation, covering machine learning on edge devices, and an optional practical part where students build, train and run a neural network image classifier in the browser.

Requirements :

Computers, Web cam, Chrome browser, Code editor

Prerequisites :

Medium level JavaScript

Learning outcomes :

basic understanding of neural network concepts

basic understanding of neural network types and applications

ability to build a trainable neural network running in the browser

basic understanding how training data affects predictive capabilities

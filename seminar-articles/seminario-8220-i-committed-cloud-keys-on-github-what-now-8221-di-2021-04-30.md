Developers routinely use GitHub to back up, share, and manage changes to code. GitHub code repositories are usually public. Anyone can find and access code. Working with cloud resources means using secret keys and tokens to access and interact with services. Malicious hackers know that developers often forget to remove sensitive data before pushing on GitHub, so they scan and scrape repositories for this data.
This seminar will talk about protecting sensitive data when working with cloud as developers, going through some real experiences, and providing some best practices.

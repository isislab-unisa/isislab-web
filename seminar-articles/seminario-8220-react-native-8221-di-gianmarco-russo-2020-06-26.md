La creazione di app mobile compatibili con più piattaforme è un compito noioso e pone sfide importanti davanti a uno sviluppatore in quanto deve avere le conoscenze specifiche di due o più piattaforme native. Esistono alcuni framework per facilitare questo compito ma pongono delle limitazioni. React Native è un framework che permette di costruire applicazioni per iOS ed Android utilizzando i componenti che realmente vengono messi a disposizione da essi ma usando JavaScript e React per posizionarli e per definire la logica. In questo seminario condividerò le mie conoscenze su questo framework.

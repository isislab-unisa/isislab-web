<section class="info-box" aria-labelledby="simulazioni-ad-agenti-su-larga-scala"><h2 id="simulazioni-ad-agenti-su-larga-scala">Simulazioni ad agenti su larga scala</h2>
<p><strong>Pubblicazioni</strong></p>
<ul>
<li><a href="https://doi.org/10.1177/0037549713489594">Bringing together efficiency and effectiveness in distributed simulations: The experience with D-Mason</a> (2013)</li>
<li><a href="https://dblp.org/rec/conf/bighpc/AmbrosioVFSS25">The Impact of ECS Logic on Parallel Performance in Agent-based Model Simulations</a> (2025)</li>
</ul>
<p><strong>Altri riferimenti</strong> · <a href="https://journals.sagepub.com/doi/abs/10.1177/0037549713489594">D-MASON</a> · <a href="https://github.com/krABMaga/krABMaga">Il simulatore krABMaga</a></p>
<p>Da D-MASON a krABMaga, il laboratorio sviluppa ambienti che permettono di descrivere i comportamenti individuali e osservare i fenomeni collettivi che emergono dalle loro interazioni. La ricerca affronta il problema di distribuire gli agenti tra più unità di calcolo, bilanciando il lavoro anche quando gli agenti si concentrano in alcune regioni dello spazio simulato.</p>
<ul aria-label="Categorie ACM CCS 2012">
<li>CCS → Computing methodologies → Modeling and simulation → Simulation types and techniques → <a href="https://dl.acm.org/ccs/ccs.cfm?id=10010355&amp;lid=0.10010147.10010341.10010349.10010355">Agent / discrete models</a></li>
<li>CCS → Computing methodologies → Modeling and simulation → Simulation types and techniques → <a href="https://dl.acm.org/ccs/ccs.cfm?id=10010356&amp;lid=0.10010147.10010341.10010349.10010356">Distributed simulation</a></li>
</ul>
</section>

<section class="info-box" aria-labelledby="architetture-parallele"><h2 id="architetture-parallele">Architetture Parallele</h2>
<p><strong>Pubblicazioni</strong></p>
<ul>
<li><a href="https://doi.org/10.1016/j.future.2025.108032">miniLB: Benchmarking Lattice Boltzmann simulations on AMD, Intel, and NVIDIA GPUs</a> (2026)</li>
<li><a href="https://doi.org/10.1145/3754598.3754615">SYgraph: A Portable Heterogeneous Graph Analytics Framework for GPUs</a> (2025)</li>
</ul>
<p>Il laboratorio studia come le caratteristiche delle architetture parallele incidano sulle prestazioni delle applicazioni. Con il benchmark miniLB confronta l’esecuzione di una stessa simulazione su GPU di produttori diversi. Con il framework SYgraph affronta un problema complementare, la portabilità degli algoritmi di analisi dei grafi su GPU.</p>
<ul aria-label="Categorie ACM CCS 2012">
<li>CCS → Computer systems organization → Architectures → <a href="https://dl.acm.org/ccs/ccs.cfm?id=10010528&amp;lid=0.10010520.10010521.10010528">Parallel architectures</a></li>

<section class="info-box" aria-labelledby="algoritmi-per-grafi-e-ipergrafi"><h2 id="algoritmi-per-grafi-e-ipergrafi">Algoritmi per grafi e ipergrafi</h2>
<p><strong>Pubblicazioni</strong></p>
<ul>
<li><a href="https://doi.org/10.1007/s00224-007-9074-x">Degree-Optimal Routing for P2P Systems</a> (2009)</li>
<li><a href="https://doi.org/10.3390/e23070796">Social Influence Maximization in Hypergraphs</a> (2021)</li>
</ul>
<p>Tra i primi contributi su grafi e reti, il laboratorio ha studiato come ridurre il numero di collegamenti necessari per instradare una richiesta in una rete peer-to-peer. Nei lavori successivi sugli ipergrafi ha esaminato come scegliere i nodi da cui avviare un processo di diffusione quando le interazioni coinvolgono interi gruppi.</p>

<section aria-labelledby="calcolo-collaborativo-e-sociale" style="margin: 35px 0; padding: 28px; background: #f5f7fa; border: 1px solid #dce3eb; border-radius: 12px;"><h1 id="calcolo-collaborativo-e-sociale" class="wp-block-heading">Calcolo Collaborativo e Sociale</h1>
<section class="info-box" aria-labelledby="sistemi-collaborativi-open-data-e-learning"><h2 id="sistemi-collaborativi-open-data-e-learning">Sistemi collaborativi, open data e learning</h2>
<p><strong>Pubblicazioni</strong></p>
<ul>
<li><a href="https://doi.org/10.1109/COLCOM.2007.4553836">CoFFEE : Cooperative Face2Face educational environment</a> (2007)</li>
</ul>
<p><strong>Progetti</strong> · <a href="/progetti/route-to-pa/">ROUTE-TO-PA</a> · <a href="/progetti/lead/">LEAD</a></p>
<p><strong>Altri riferimenti</strong> · <a href="https://cordis.europa.eu/project/id/645860/it">Il progetto ROUTE-TO-PA su CORDIS (2015–2018)</a></p>
<p>Il laboratorio progetta e valuta strumenti con cui gruppi di persone possono produrre dati, discutere e prendere decisioni insieme. Nel progetto europeo ROUTE-TO-PA, cittadini e amministrazioni hanno utilizzato la Social Platform for Open Data per costruire e interpretare dati aperti. In ambito educativo, CoFFEE ha permesso ai docenti di organizzare discussioni in piccoli gruppi e studiare la partecipazione degli studenti. Queste esperienze si affiancano alle ricerche sulla didattica dell’informatica e dell’intelligenza artificiale.</p>
<ul aria-label="Categorie ACM CCS 2012">
<li>CCS → Information systems → Information systems applications → <a href="https://dl.acm.org/ccs/ccs.cfm?id=10003233&amp;lid=0.10002951.10003227.10003233">Collaborative and social computing systems and tools</a></li>
<li>CCS → Applied computing → Education → <a href="https://dl.acm.org/ccs/ccs.cfm?id=10010490&amp;lid=0.10010405.10010489.10010490">Computer-assisted instruction</a></li>
</ul>
</section>

<section class="info-box" aria-labelledby="analisi-delle-reti-sociali"><h2 id="analisi-delle-reti-sociali">Analisi delle reti sociali</h2>
<p><strong>Pubblicazioni</strong></p>
<ul>
<li><a href="https://doi.org/10.1016/J.TCS.2018.02.024">Active influence spreading in social networks</a> (2019)</li>
<li><a href="https://doi.org/10.1007/978-3-032-02555-5_19">Stay and Play - Modeling Social Influence of Players in the Steam Gaming Community</a> (2025)</li>
</ul>
<p><strong>Altri riferimenti</strong> · <a href="https://doi.org/10.3390/e23070796">Diffusione dell’influenza negli ipergrafi</a></p>
<p>Come si diffonde un’informazione quando le persone interagiscono in gruppi? ISISLab studia come la struttura delle relazioni influenzi la propagazione dell’informazione. Un problema concreto è individuare un piccolo insieme di persone da cui avviare la diffusione affinché raggiunga l’intera rete. I modelli basati su ipergrafi permettono di studiare il ruolo dei gruppi in questo processo.</p>
<ul aria-label="Categorie ACM CCS 2012">
<li>CCS → Human-centered computing → Collaborative and social computing → Collaborative and social computing design and evaluation methods → <a href="https://dl.acm.org/ccs/ccs.cfm?id=10003293&amp;lid=0.10003120.10003130.10003134.10003293">Social network analysis</a></li>
</ul>
</section>

<section class="info-box" aria-labelledby="web-semantico-e-knowledge-graph"><h2 id="web-semantico-e-knowledge-graph">Web semantico e Knowledge graphs</h2>
<p><strong>Pubblicazioni</strong></p>
<ul>
<li><a href="https://doi.org/10.1145/3786331">Lost in LOD: Analyzing the Linked Open Data Cloud Quality Maze</a> (2026)</li>
<li><a href="https://doi.org/10.1145/3701716.3717809">From Quality Reports to Knowledge Graphs: a Case Study on CSV-to-KG Transformation</a> (2025)</li>
</ul>
<p>Per riutilizzare dati pubblicati da organizzazioni diverse occorre sapere che cosa descrivono, come sono collegati e quanto sono affidabili. Il laboratorio studia la rappresentazione della conoscenza mediante <em>knowledge graph</em>, la trasformazione di dati tabellari in RDF e l’interrogazione di fonti distribuite. Un tema centrale è la qualità dei <em>Linked Open Data</em>. Le ricerche riguardano sia la valutazione di intere collezioni di dati collegati, sia la rappresentazione dei risultati delle valutazioni in una forma che altri sistemi possano interrogare e riutilizzare.</p>
<ul aria-label="Categorie ACM CCS 2012">
<li>CCS → Information systems → World Wide Web → Web data description languages → <a href="https://dl.acm.org/ccs/ccs.cfm?id=10003315&amp;lid=0.10002951.10003260.10003309.10003315">Semantic web description languages</a></li>
</ul>
</section>

<section class="info-box" aria-labelledby="intelligenza-artificiale-per-reti-e-dati-semantici"><h2 id="intelligenza-artificiale-per-reti-e-dati-semantici">Intelligenza artificiale per reti e dati semantici</h2>
<p><strong>Pubblicazioni</strong></p>
<ul>
<li><a href="https://doi.org/10.1145/3690624.3709274">Hypergraph Motif Representation Learning</a> (2025)</li>
<li><a href="https://doi.org/10.1145/3630744.3658418">Deciphering Conversational Networks: Stance Detection via Hypergraphs and LLMs</a> (2024)</li>
<li><a href="https://dblp.org/rec/journals/corr/abs-1808-00434">Leveraging Knowledge Graph Embedding Techniques for Industry 4.0 Use Cases</a> (2018)</li>
</ul>
<p><strong>Altri riferimenti</strong> · <a href="https://neurips.cc/virtual/2026/loc/sydney/poster/154651">Hypergraph Generation with Latent Diffusion</a> · <a href="https://github.com/isislab-unisa/KGSum">KGSum</a></p>
<p>ISISLab studia metodi di machine learning che sfruttano le relazioni tra gli elementi di un insieme di dati. Negli ipergrafi, per esempio, il laboratorio analizza come ricavare rappresentazioni dalle configurazioni ricorrenti di interazioni tra gruppi e come generare nuove strutture mediante modelli di diffusione. Un secondo filone riguarda l’impiego di large language models (LLM) per descrivere e classificare i knowledge graph. Lo strumento KGSum integra questi modelli con tecniche di machine learning per caratterizzare collezioni di grafi.</p>
<ul aria-label="Categorie ACM CCS 2012">
<li>CCS → Computing methodologies → Machine learning → Machine learning approaches → <a href="https://dl.acm.org/ccs/ccs.cfm?id=10010319&amp;lid=0.10010147.10010257.10010293.10010319">Learning latent representations</a></li>
</ul>
</section>
